# 埼玉 VS 波罗斯 — 像素火柴人战斗 (Pixel Stickman Fight)

A fully procedural pixel-art stickman brawl: Saitama (cream stick, red fists, little cape) vs Boros
(violet stick, spiky hair, one red eye). No story, no dialogue: about 30 s of continuous, choreographed action
built for impact. Every frame, effect, sound effect and note is generated by code.

- **Output**: 1920×1080 @ 60 fps, H.264 + AAC (`out/saitama_vs_boros.mp4`)
- **Native canvas**: 384×216, nearest-neighbour ×5 upscale + subtle scanlines

## Run

```bash
pip install numpy pillow imageio-ffmpeg
python render.py all 4                 # full video, 4 worker processes
python render.py sheet 6 5             # contact sheet of the whole fight -> out/sheet.png
python render.py sheet 4 3 20.0 26.0   # contact sheet of a time range (real seconds)
```

## 动作编排 Choreography (`film.py`)

1. FIGHT! → 波罗斯冲刺三连击被格挡 → 闪避反击
2. 11 连拳暴风格挡 → 埼玉瞬移到背后，一拳打飞，撞墙
3. 波罗斯破墙冲回，升龙拳挑空 → 空中连段 → 双手锤砸地成坑
4. 埼玉普通一拳：波罗斯连穿两栋大楼，镜头甩镜追随
5. 波罗斯觉醒（气场爆发）→ 瞬移围攻五连（上、下、左、右）→ 对拳
6. 空中高速战：格挡、两次对拳、踢飞、追击、双手锤把埼玉砸回地面
7. 崩星咆哮炮蓄力 → 光束吞没埼玉（剪影）→ 埼玉逆着光束冲上去
8. 慢镜蓄力 → 认真一拳：冲击帧、冲击锥、劈开云层，波罗斯化为光尘 → K.O.

## 打击感是怎么做的

- **Hit-stop time map**: the fight is authored in story time; each hit declares a stop length by weight
  (block 35 ms … heavy 150 ms … serious punch 400 ms). The time map freezes story time on contact, while camera shake
  and sparks keep moving in real time. The serious-punch windup uses a slow-motion segment.
- **Hit feedback by weight** (`KINDS`): directional spark bursts, impact stars, shockwave rings, camera trauma,
  zoom kick, anime 2-tone impact frames, chromatic aberration, focus lines, lightning (clashes), ground craters with
  glowing fissures and debris (slams), destructible buildings (wall hits), combo counter.
- **Automatic motion FX**: fists and feet leave smear arcs whenever they move fast, fast bodies leave afterimages,
  ground skids kick up dust and sparks, and teleports draw light streaks.
- **Auto camera**: frames both fighters (center + zoom from their spread), smoothed follow; per-beat overrides for
  focus, zoom bias and follow speed (whip pans).
- **Sound** (`audio.py`): every hit's SFX is placed at its *real* (post-hit-stop) time over a 172 BPM chiptune loop
  that drops out for the serious-punch windup.

Engine pieces: `engine.py` (canvas, bloom, dithering, text), `stick.py` (stickman renderer), `fighters.py`
(skeleton, poses, cape physics), `fx.py`, `backgrounds.py`, `shotbase.py` (smears / ghosts / glints).
