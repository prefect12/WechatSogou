# 埼玉 VS 波罗斯 — 像素风战斗短片 (Pixel Fan Animation)

A fully procedural, pixel-art fan animation of *One Punch Man*'s Saitama vs. Lord Boros.
Every frame, sprite, effect, sound effect and note of music is generated by code: no external assets.

- **Output**: 1920×1080 @ 60 fps, ~64 s, H.264 + AAC (`out/saitama_vs_boros.mp4`)
- **Native canvas**: 384×216 (CPS2-style arcade grid), nearest-neighbour ×5 upscale + subtle scanlines

## Run

```bash
pip install numpy pillow imageio-ffmpeg
python render.py all --jobs 4      # full video -> out/saitama_vs_boros.mp4
python render.py sheet S10 4 3     # contact sheet of one shot (for reviewing the storyboard)
```

## 技术要点

- **Skeletal pixel sprites** (`fighters.py`): body parts are vector capsules/polygons rasterised *without anti-aliasing*
  straight onto the pixel grid, so the camera can zoom from wide shots to extreme close-ups while pixels stay crisp.
  Per-part cel shading is computed by shifting each part mask along the light vector (shadow band / highlight band),
  plus selective inner outlines, a 1px outer outline and **dynamic rim lights** from in-scene light sources.
- **Physics**: Saitama's cape and Boros' hair are verlet chains driven by wind + inertia.
- **Animation**: keyframed pose tracks with snappy easing, poses stepped "on twos" (30 fps) over a 60 fps camera/FX
  layer — the classic sprite feel, but with fluid camera and effects.
- **FX** (`fx.py`): particle system (sparks, embers, dithered dust), rigid debris, shockwave rings, impact stars,
  lightning (midpoint displacement), energy orb, beam, glowing ground fissures, afterimages, fist smears, flame aura.
- **Cinematics**: screen shake (trauma model), hit-stop, anime impact frames (adaptive 2-tone), chromatic aberration,
  whip-pan motion smear, focus/speed lines, letterboxing, typewriter subtitles, move-name banners.
- **Lighting & post** (`engine.py`): HDR emissive layer → two-scale blocky bloom, overexposure to white, soft clip,
  vignette, ordered (Bayer) dithering to a limited palette so gradients band like real pixel art.
- **Backgrounds** (`backgrounds.py`): parallax ruined city with fires and lit windows, dithered fbm clouds (which can
  be *split* by the Serious Punch), Boros' mothership, starfield, procedurally shaded Earth, lunar surface.
- **Audio** (`audio.py`): chiptune score (A-minor battle loop, pads, drum rolls) laid out against the edit, plus ~40
  synthesized SFX; mixed to stereo WAV and muxed with ffmpeg.
